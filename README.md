# Самолёты в воздушном пространстве страны

Курсовой проект на Python получает название страны, находит её географические
границы через Nominatim (OpenStreetMap), запрашивает самолёты в этом
прямоугольнике через OpenSky Network, сохраняет результат в JSON и выводит
отфильтрованный топ по высоте.

## Как это работает

```text
Название страны
      │
      ▼
Nominatim API ──► south, north, west, east
      │
      ▼
OpenSky API ────► массивы состояний самолётов
      │
      ▼
Aeroplane ──────► фильтрация ─► топ N ─► консоль
      │
      └─────────► data/aeroplanes.json
```

API здесь — обычный HTTP-запрос. Программа отправляет `GET` на адрес сервиса,
передаёт параметры и получает JSON. В проекте `requests` делает сам HTTP-запрос,
а наш код проверяет статус ответа и переводит JSON в объекты `Aeroplane`.

1. `Nominatim /search` получает `country=France` и возвращает
   `boundingbox = [south, north, west, east]`.
2. Эти четыре числа отправляются в `OpenSky /states/all` как `lamin`, `lamax`,
   `lomin`, `lomax`.
3. OpenSky возвращает поле `states`. У него каждый самолёт представлен массивом,
   поэтому `Aeroplane.from_state_vector()` даёт индексам понятные названия.

Прямоугольник приблизительный: вместе со страной в него могут попасть части
соседних стран. Это ожидаемое ограничение задания.

## Быстрый запуск

Нужен Python 3.10 или новее. В PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
python main.py
```

Результат сохраняется в `data/aeroplanes.json`. Этот файл намеренно добавлен в
`.gitignore`, потому что это изменяющиеся данные API, а не исходный код.

## Нужен ли ключ OpenSky

Нет, для проверки проекта можно ничего не настраивать: запрос `/states/all`
доступен анонимно. У анонимного режима меньше суточный лимит.

OpenSky больше не принимает логин и пароль через Basic Auth. Для авторизованного
режима нужно создать API client на странице аккаунта OpenSky и получить
`client_id` и `client_secret`. Затем:

```powershell
Copy-Item .env.example .env
```

Заполните в `.env`:

```dotenv
OPENSKY_CLIENT_ID=ваш_client_id
OPENSKY_CLIENT_SECRET=ваш_client_secret
```

`main.py` загрузит `.env`, клиент получит OAuth2-токен и сам добавит заголовок
`Authorization: Bearer ...`. Секрет не попадёт в Git: `.env` игнорируется.

Если задана только одна из двух переменных, программа специально завершит запрос
с понятным сообщением, а не отправит поломанную авторизацию.

## Структура

```text
cursovaya_2
├── data
├── src/aviation_tracker
│   ├── api.py       # ABC, Nominatim, OpenSky и OAuth2
│   ├── models.py    # инкапсулированная модель Aeroplane
│   ├── storage.py   # ABC и JSONSaver
│   ├── services.py  # фильтры, диапазон и сортировка DESC
│   └── cli.py       # общение с пользователем
├── tests
├── main.py
└── pyproject.toml
```

`AbstractAeroplanesAPI` и `AbstractSaver` задают интерфейсы, а конкретные классы
реализуют их. Благодаря этому источник API или JSON-хранилище можно заменить без
изменения пользовательского сценария (первые два принципа SOLID: SRP и OCP).

Операторы `<`, `>`, `<=`, `>=` сравнивают самолёты по высоте. Методы
`compare_altitude()` и `compare_speed()` позволяют явно сравнить как высоту, так
и скорость. Неизвестные значения OpenSky корректно обрабатываются и при
сортировке считаются меньшими известных.

## Тесты

```powershell
pytest
```

Внешние сервисы в тестах не вызываются: ответы подменяются, поэтому тесты
быстрые и не расходуют API-лимит. `pytest-cov` проверяет покрытие не ниже 70%.

## Возможные ошибки

- `Страна ... не найдена` — попробуйте официальное или английское название.
- `HTTP 429` — исчерпан суточный лимит OpenSky; подождите обновления лимита или
  настройте OAuth2.
- `HTTP 401` — проверьте `client_id` и `client_secret`.
- Получено `0` самолётов — это допустимый живой ответ: сейчас в области может не
  быть видимых OpenSky бортов.
- Ошибка подключения — проверьте интернет, VPN/прокси и повторите запрос позже.
